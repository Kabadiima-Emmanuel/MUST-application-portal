MUST Admissions Portal 

Files
- index.html: sign-in page
- createAccount.html: account registration page
- designs.css: shared styles for both pages
- logo.png: the MUST logo

How to preview
1. Keep the four files in the same folder.
2. Open index.html in a browser. Use the links to switch between the two pages.

Documentation notes
- HTML comments explain important structure and form behavior.
- CSS comments explain reusable colors, layout, responsive rules, and accessibility styles.
- The forms currently use action="#" as placeholders. They do not authenticate users or store new accounts.
  A server-side endpoint/database integration is required for real admissions portal functionality.
- The Forgot password, terms, and privacy links are placeholders and should be connected to real pages.
